| Version | Supported          |
|---------|--------------------|
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

**Do NOT open a public GitHub issue.**

Instead, use GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/serhii-f8/filament-studio/security) of this repository
2. Choose **Report a vulnerability**
3. Include a description of the vulnerability, steps to reproduce, and the potential impact

The report stays private between you and the maintainers until a fix is released.

We will acknowledge your report within 48 hours and aim to release a fix within 7 days for critical issues.
